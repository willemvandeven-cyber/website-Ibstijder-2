# IB Strijders

Professionele, minimalistische fanwebsite voor IB Strijders.

## Pagina's
- `index.html` — Big Yahoo homepage
- `quotes.html` — Quotes
- `moments.html` — Funny Moments

## Video's
Alleen 6 geselecteerde clips worden gebruikt op de site. De overige video's hoeven niet in de GitHub-repository te staan.

## GitHub Pages
Upload de bestanden en de map `assets/videos/` naar je repository. Zet daarna GitHub Pages aan via Settings → Pages.
