# IB Strijders — Spectral Edition

Deze versie combineert de inhoud van de oorspronkelijke IB Strijders-site met de geüploade HTML5 UP Spectral-template.

## Pagina's
- `index.html` — nieuwe Spectral-style homepage
- `quotes.html` — alle 6 quotes
- `moments.html` — alle 6 video's

## Assets
De Spectral CSS/JS/font-assets en de 6 originele IB Strijders-video's zijn meegenomen.

## Gebruik
Open `index.html` lokaal of upload de volledige map naar GitHub Pages.


## Video compatibility
Video's zijn in H.264/AAC opgeslagen voor brede browsercompatibiliteit.
