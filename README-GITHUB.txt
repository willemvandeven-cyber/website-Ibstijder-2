IB STRIJDERS — GITHUB PAGES

BELANGRIJK:
Upload de INHOUD van deze map naar de root van je GitHub repository.
Dus index.html moet direct in de repository staan, niet in een extra map.

De repository moet er ongeveer zo uitzien:
index.html
quotes.html
moments.html
ib-strijders.css
ib-strijders.js
CNAME
.nojekyll
assets/
images/

GitHub Pages:
Settings -> Pages -> Deploy from a branch
Branch: main
Folder: / (root)

Custom domain:
ibstrijders.nl

De video's staan in:
assets/videos/

Alle video's zijn H.264/AAC MP4 en geschikt voor moderne browsers.
