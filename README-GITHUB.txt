IB STRIJDERS — SPECTRAL EDITION

Deze versie gebruikt de originele HTML5 UP Spectral-template als basis.
De originele Spectral assets/CSS/JS zijn behouden; de IB Strijders-inhoud is erin verwerkt.

UPLOAD:
Upload de INHOUD van deze map naar de ROOT van je GitHub repository.
index.html moet direct in de root staan.

GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> / (root)

Custom domain:
ibstrijders.nl
